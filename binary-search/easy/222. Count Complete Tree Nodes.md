# 222. Count Complete Tree Nodes
**Difficulty**: Easy

**LeetCode Link**: [222. Count Complete Tree Nodes](https://leetcode.com/problems/count-complete-tree-nodes/description/?envType=study-plan-v2&envId=top-interview-150)
---


The key to this problem is the follow-up:

> **Design an algorithm that runs in less than O(n).**

A normal DFS or BFS counts every node:

```csharp
public int CountNodes(TreeNode root) {
    if(root == null) return 0;
    return 1 + CountNodes(root.left) + CountNodes(root.right);
}
```

This is **O(n)**, which ignores the fact that the tree is **complete**.

The interviewer wants you to exploit the properties of a **complete binary tree**.

---

# What is a Complete Binary Tree?

A complete binary tree has:

1. Every level completely filled except possibly the last.
2. The last level is filled from left to right.

Example

```text
        1
      /   \
     2     3
    / \   /
   4   5 6
```

Notice only the last level is incomplete.

---

# Important Observation

Suppose we have

```text
        1
      /   \
     2     3
    / \   / \
   4  5  6  7
```

This is a **perfect binary tree**.

A perfect binary tree has

* every level full
* every leaf at the same depth

The number of nodes can be computed directly.

# Algorithm

For every subtree

Compute

* left height
* right height

If

```text
leftHeight == rightHeight
```

return

```text
2^(h+1)-1
```

Otherwise

```text
1
+
count(left)
+
count(right)
```

# C# Solution

```csharp
public class Solution
{
    public int CountNodes(TreeNode root)
    {
        if (root == null)
            return 0;

        int leftHeight = GetLeftHeight(root);
        int rightHeight = GetRightHeight(root);

        if (leftHeight == rightHeight)
            return (1 << (leftHeight + 1)) - 1;

        return 1
            + CountNodes(root.left)
            + CountNodes(root.right);
    }

    private int GetLeftHeight(TreeNode node)
    {
        int height = 0;

        while (node.left != null)
        {
            height++;
            node = node.left;
        }

        return height;
    }

    private int GetRightHeight(TreeNode node)
    {
        int height = 0;

        while (node.right != null)
        {
            height++;
            node = node.right;
        }

        return height;
    }
}
```

---

# Why Does This Work?

For a **complete binary tree**, if the leftmost and rightmost heights are equal, then **every level must be completely filled**.

There can't be any missing nodes in the middle because complete trees only allow missing nodes on the **right side of the last level**.

Therefore,

```text
leftHeight == rightHeight
```

implies

```text
Perfect tree
```

---

# Complexity

Suppose the tree has height **h**.

Each recursive call computes two heights.

Each height computation costs

```text
O(h)
```

The recursion depth is also

```text
O(h)
```

Total

```text
O(h²)
```

Since

```text
h = log n
```

the overall complexity is

```text
O((log n)²)
```

which satisfies the requirement of being **better than O(n)**.

Space complexity:

```text
O(log n)
```

due to the recursion stack.

# Interview Takeaways

The interviewer expects you to recognize that:

1. The tree is **complete**, so you should use that property.

2. A subtree with equal leftmost and rightmost heights is **perfect**.

3. A perfect binary tree's node count can be computed directly using:

   ```text
   nodes = 2^(height + 1) - 1
   ```

4. Only recurse into subtrees that are not perfect, giving an overall complexity of **O((log n)²)** instead of **O(n)**.
