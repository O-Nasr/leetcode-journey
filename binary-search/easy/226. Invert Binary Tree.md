# 226. Invert Binary Tree
**Difficulty**: Easy

**LeetCode Link**: [226. Invert Binary Tree](https://leetcode.com/problems/invert-binary-tree/description/?envType=study-plan-v2&envId=top-interview-150) (Easy)
---

This is one of the classic binary tree problems. The idea is very simple:

> **For every node, swap its left and right child.**

You can do this either recursively or iteratively (using a queue or stack).

---

## Recursive Solution (DFS)

### Idea

For each node:

1. Swap `left` and `right`
2. Invert the left subtree
3. Invert the right subtree

Since every subtree is also a binary tree, recursion fits naturally.

### Visualization

Original tree

```text
        4
      /   \
     2     7
    / \   / \
   1   3 6   9
```

Swap children of 4

```text
        4
      /   \
     7     2
    / \   / \
   6   9 1   3
```

Now recursively invert subtree rooted at 7.

```
    7
   / \
  6   9
```

becomes

```
    7
   / \
  9   6
```

Likewise,

```
    2
   / \
  1   3
```

becomes

```
    2
   / \
  3   1
```

Final result

```text
        4
      /   \
     7     2
    / \   / \
   9   6 3   1
```

## C# Solution

```csharp
public class Solution
{
    public TreeNode InvertTree(TreeNode root)
    {
        if (root == null)
            return null;

        // Swap children
        TreeNode temp = root.left;
        root.left = root.right;
        root.right = temp;

        // Invert subtrees
        InvertTree(root.left);
        InvertTree(root.right);

        return root;
    }
}
```

## Cleaner C# Version

```csharp
public class Solution
{
    public TreeNode InvertTree(TreeNode root)
    {
        if (root == null)
            return null;

        (root.left, root.right) = (root.right, root.left);

        InvertTree(root.left);
        InvertTree(root.right);

        return root;
    }
}
```

# Why do we swap before recursion?

Suppose we have

```text
    2
   / \
  1   3
```

After swapping

```text
    2
   / \
  3   1
```

Then we recurse on the new left (`3`) and new right (`1`).

It also works if you recurse first and swap afterward because both subtrees will eventually be inverted. The order doesn't matter as long as every node gets swapped exactly once.

# Iterative Solution (BFS)

Instead of recursion, use a queue.

### Algorithm

1. Put the root into the queue.
2. While the queue isn't empty:

   * Pop a node.
   * Swap its children.
   * Push non-null children.

### C#

```csharp
public class Solution
{
    public TreeNode InvertTree(TreeNode root)
    {
        if (root == null)
            return null;

        Queue<TreeNode> queue = new Queue<TreeNode>();
        queue.Enqueue(root);

        while (queue.Count > 0)
        {
            TreeNode node = queue.Dequeue();

            (node.left, node.right) = (node.right, node.left);

            if (node.left != null)
                queue.Enqueue(node.left);

            if (node.right != null)
                queue.Enqueue(node.right);
        }

        return root;
    }
}
```

---

# Time Complexity

Every node is visited exactly once.

* **Time:** **O(n)**

---

# Space Complexity

### Recursive DFS

* Worst case (completely skewed tree): **O(n)** recursion stack.
* Balanced tree: **O(log n)** recursion stack.

### Iterative BFS

The queue stores nodes level by level.

* Worst case: **O(n)**
* Balanced tree: about **O(n/2)** at the widest level, which is still **O(n)**.
