# 101. Symmetric Tree
**Difficulty**: Easy

**LeetCode Link**: [101. Symmetric Tree](https://leetcode.com/problems/symmetric-tree/description/?envType=study-plan-v2&envId=top-interview-150) (Easy)
---

This is one of the most important binary tree interview questions because it teaches you **how to compare two trees simultaneously**.

Many people first think:

> "I should compare the left subtree and the right subtree."

That's correct, but **not in the normal way**. You have to compare them as **mirror images**.

---

# Understanding the Problem

Consider this tree:

```text
        1
      /   \
     2     2
    / \   / \
   3   4 4   3
```

This tree is symmetric because the left side is the mirror image of the right side.

Notice the comparisons:

```
left.left  == right.right
left.right == right.left
```

NOT

```
left.left == right.left   ❌
left.right == right.right ❌
```

This is the most important observation.

---

## Example 2

```text
        1
      /   \
     2     2
      \     \
       3     3
```

Mirror comparison:

```
left.left  -> null
right.right -> 3

null != 3
```

Therefore the answer is **false**.

---

# Recursive Solution

Instead of asking

> "Is this tree symmetric?"

Ask

> "Are these two trees mirrors of each other?"

Create a helper function:

```text
IsMirror(leftSubtree, rightSubtree)
```

---

## Mirror Conditions

Two trees are mirrors if:

### 1. Both are null

```text
null      null
```

Mirror → true

---

### 2. One is null

```text
null      5
```

Mirror → false

---

### 3. Values differ

```text
3      4
```

Mirror → false

---

### 4. Current nodes match

Then compare

```text
left.left   with right.right

AND

left.right  with right.left
```

---

## Visualization

Suppose

```text
        1
      /   \
     A     B
```

We compare

```
A with B
```

Now compare their children

```
A.left  <-> B.right

A.right <-> B.left
```

Notice the crossing:

```text
      A             B
    /   \         /   \
  AL    AR      BL    BR

Compare

AL <------> BR

AR <------> BL
```

That crossing is exactly what "mirror" means.

---

# Recursive Algorithm

```
IsMirror(left, right)

if both null
    return true

if one null
    return false

if values differ
    return false

return
    IsMirror(left.left, right.right)
&&
    IsMirror(left.right, right.left)
```

---

# C# Solution

```csharp
public class Solution
{
    public bool IsSymmetric(TreeNode root)
    {
        return IsMirror(root.left, root.right);
    }

    private bool IsMirror(TreeNode left, TreeNode right)
    {
        if (left == null && right == null)
            return true;

        if (left == null || right == null)
            return false;

        if (left.val != right.val)
            return false;

        return IsMirror(left.left, right.right)
            && IsMirror(left.right, right.left);
    }
}
```

# Why doesn't comparing left with left work?

Suppose

```text
        1
      /   \
     2     2
    /       \
   3         3
```

Correct comparison:

```
left.left = 3

right.right = 3
```

Mirror ✔

If you compared

```
left.left

right.left
```

you'd compare

```
3

null
```

which is incorrect.

---

# Iterative Solution (Queue)

Instead of recursion, store node pairs that should mirror each other.

Initially:

```
(root.left, root.right)
```

Every time you remove a pair:

Check

* both null → continue
* one null → false
* values differ → false

Otherwise enqueue:

```
(left.left, right.right)

(left.right, right.left)
```

Again notice the crossing.

---

# C# Iterative

```csharp
public class Solution
{
    public bool IsSymmetric(TreeNode root)
    {
        Queue<TreeNode> queue = new Queue<TreeNode>();

        queue.Enqueue(root.left);
        queue.Enqueue(root.right);

        while (queue.Count > 0)
        {
            TreeNode left = queue.Dequeue();
            TreeNode right = queue.Dequeue();

            if (left == null && right == null)
                continue;

            if (left == null || right == null)
                return false;

            if (left.val != right.val)
                return false;

            queue.Enqueue(left.left);
            queue.Enqueue(right.right);

            queue.Enqueue(left.right);
            queue.Enqueue(right.left);
        }

        return true;
    }
}
```

# Complexity Analysis

## Recursive

### Time

Every node is visited once.

```
O(n)
```

### Space

Recursion stack:

* Balanced tree: `O(log n)`
* Skewed tree: `O(n)`

---

## Iterative

### Time

```
O(n)
```

### Space

The queue can hold up to one level of the tree.

Worst case:

```
O(n)
```

# Interview Pattern to Remember

This problem introduces a very common interview pattern: **pairwise tree traversal**.

For normal tree recursion, you recurse on one node:

```csharp
DFS(node)
```

For symmetry (and many tree comparison problems), you recurse on **two nodes at the same time**:

```csharp
DFS(node1, node2)
```

The key insight is to compare them in a mirrored fashion:

```text
node1.left  ↔ node2.right
node1.right ↔ node2.left
```

Whenever you see phrases like **"mirror," "symmetric,"** or **"are these two trees identical?"**, think in terms of traversing **two nodes together** rather than traversing a single tree. This pattern also appears in problems such as **Same Tree**, **Subtree of Another Tree**, and **Flip Equivalent Binary Trees**.
