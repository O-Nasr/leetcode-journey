[130. Surrounded Regions](https://leetcode.com/problems/surrounded-regions/description/?envType=study-plan-v2&envId=top-interview-150) (Medium)
---


Given a board containing `'X'` and `'O'`, convert every region of `'O'` that is completely surrounded by `'X'` into `'X'`.

Example:

```text
X X X X
X O O X
X X O X
X O X X
```

becomes:

```text
X X X X
X X X X
X X X X
X O X X
```

---

## Main Insight

Instead of trying to find the surrounded regions directly, we find the regions that are **not surrounded**.

An `'O'` is safe if it can reach the border.

So the algorithm is:

### Step 1: Start from border `'O'` cells

Run DFS/BFS and mark all connected `'O'` cells as safe:

```text
'O' → '#'
```

### Step 2: Traverse the board

* Remaining `'O'` cells are trapped → convert to `'X'`.
* Safe cells (`'#'`) are restored back to `'O'`.

---

## Example

Initial board:

```text
X X X X
X O O X
X X O X
X O X X
```

Border `'O'`:

```text
(3,1)
```

After DFS:

```text
X X X X
X O O X
X X O X
X # X X
```

Convert remaining `'O'` to `'X'`:

```text
X X X X
X X X X
X X X X
X # X X
```

Restore `'#'`:

```text
X X X X
X X X X
X X X X
X O X X
```

## DFS Solution in C#

```csharp
public class Solution
{
    public void Solve(char[][] board)
    {
        int rows = board.Length;
        int cols = board[0].Length;

        void DFS(int r, int c)
        {
            if (r < 0 || r >= rows ||
                c < 0 || c >= cols ||
                board[r][c] != 'O')
            {
                return;
            }

            board[r][c] = '#';

            DFS(r + 1, c);
            DFS(r - 1, c);
            DFS(r, c + 1);
            DFS(r, c - 1);
        }

        // Left and right borders
        for (int r = 0; r < rows; r++)
        {
            DFS(r, 0);
            DFS(r, cols - 1);
        }

        // Top and bottom borders
        for (int c = 0; c < cols; c++)
        {
            DFS(0, c);
            DFS(rows - 1, c);
        }

        // Final pass
        for (int r = 0; r < rows; r++)
        {
            for (int c = 0; c < cols; c++)
            {
                if (board[r][c] == 'O')
                    board[r][c] = 'X';
                else if (board[r][c] == '#')
                    board[r][c] = 'O';
            }
        }
    }
}
```

### Pattern we identified

This problem teaches an important graph pattern:

```text
Don't search for the bad nodes.
Search for the guaranteed-safe nodes first.
```

This same idea appears later in problems like:

* Pacific Atlantic Water Flow
* Multi-source BFS problems
* Escape problems
* Flood Fill variants
