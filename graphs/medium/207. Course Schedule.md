# 🔥 DFS Cycle Detection

We use 3 states:

| State | Meaning   |
| ----- | --------- |
| 0     | unvisited |
| 1     | visiting  |
| 2     | visited   |

---

# 🧠 VERY IMPORTANT IDEA

Suppose DFS path:

```text id="ojlwma"
0 → 1 → 2
```

Now during DFS:

```text id="njlwmb"
If we revisit a VISITING node
```

then:

```text id="mjlwmc"
Cycle exists
```

because we're returning to current recursion path.

---

# ✅ C# Code

```csharp id="fjlwmj"
public class Solution
{
    public bool CanFinish(int numCourses, int[][] prerequisites)
    {
        // graph
        var graph = new List<int>[numCourses];

        for (int i = 0; i < numCourses; i++)
        {
            graph[i] = new List<int>();
        }

        // build graph
        foreach (var pre in prerequisites)
        {
            int course = pre[0];
            int prereq = pre[1];

            graph[prereq].Add(course);
        }

        // 0 = unvisited
        // 1 = visiting
        // 2 = visited
        int[] state = new int[numCourses];

        for (int i = 0; i < numCourses; i++)
        {
            if (HasCycle(i))
                return false;
        }

        return true;

        bool HasCycle(int course)
        {
            // currently in recursion stack
            if (state[course] == 1)
                return true;

            // already processed
            if (state[course] == 2)
                return false;

            // mark visiting
            state[course] = 1;

            foreach (int next in graph[course])
            {
                if (HasCycle(next))
                    return true;
            }

            // mark finished
            state[course] = 2;

            return false;
        }
    }
}
```

# 🔥 Cycle Detection Logic

Suppose:

```text id="cjlwmm"
2 → 1
```

Then:

```text id="bjlwmn"
HasCycle(1)
```

called again WHILE already visiting.

That means:

```text id="ajlwmo"
Cycle
```

---

# 🧠 Why state=2 matters

Without it:

```text id="zjlwmp"
Repeated DFS work
```

Visited nodes already proven safe.
