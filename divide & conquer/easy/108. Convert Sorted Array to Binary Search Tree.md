# 108. Convert Sorted Array to Binary Search Tree
**Difficulty**: Easy

**LeetCode Link**: [108. Convert Sorted Array to Binary Search Tree](https://leetcode.com/problems/convert-sorted-array-to-binary-search-tree/description/?envType=study-plan-v2&envId=top-interview-150) (Easy)
---

This is one of the classic **Divide & Conquer** tree problems. The biggest clue is in the phrase:

> **height-balanced BST**

Let's derive the solution instead of memorizing it.

---

# Step 1: What is a BST?

A BST satisfies:

```text
Left subtree < Root < Right subtree
```

Your array is already sorted:

```text
[-10, -3, 0, 5, 9]
```

So if we choose:

```text
0
```

as the root, then:

Left side:

```text
[-10, -3]
```

Right side:

```text
[5, 9]
```

Both automatically satisfy the BST property.

---

# Step 2: Why choose the middle?

Suppose you choose the first element.

```text
-10
```

The tree becomes:

```text
-10
    \
    -3
      \
       0
         \
          5
            \
             9
```

This is basically a linked list.

Height:

```text
O(n)
```

Not balanced.

---

Suppose instead you choose the middle.

```text
      0
     / \
   ?     ?
```

Now both sides have almost the same number of nodes.

That's exactly what **height-balanced** means.

---

# Step 3: Repeat the Same Idea

Left half:

```text
[-10, -3]
```

Middle:

```text
-3
```

Right half:

```text
[5, 9]
```

Middle:

```text
9
```

Now we have

```text
        0
      /   \
    -3     9
   /      /
-10      5
```

Done.

Notice we're solving the **same problem** on smaller arrays.

That's the definition of **Divide & Conquer**.

---

# Step 4: Recursive Thinking

Write a function:

```text
Build(left, right)
```

Meaning:

> Build a balanced BST using the subarray from `left` to `right`.

---

### Base case

If

```text
left > right
```

there are no elements.

Return

```text
null
```

---

### Recursive step

Choose

```text
mid = (left + right) / 2
```

Create node:

```text
nums[mid]
```

Its left child:

```text
Build(left, mid-1)
```

Its right child:

```text
Build(mid+1, right)
```

Exactly the same problem.

---

# Visual Recursion Tree

For

```text
[-10,-3,0,5,9]
```

```
Build(0,4)

        0
      /   \

Build      Build
(0,1)      (3,4)

    -3        9
    /         /

Build      Build
(0,0)      (3,3)

-10          5
```

Notice every recursive call builds one subtree.

---

# C# Solution

```csharp
public TreeNode SortedArrayToBST(int[] nums)
{
    return Build(nums, 0, nums.Length - 1);
}

private TreeNode Build(int[] nums, int left, int right)
{
    if (left > right)
        return null;

    int mid = left + (right - left) / 2;

    TreeNode root = new TreeNode(nums[mid]);

    root.left = Build(nums, left, mid - 1);
    root.right = Build(nums, mid + 1, right);

    return root;
}
```

---

# Why use this midpoint formula?

Instead of:

```csharp
int mid = (left + right) / 2;
```

prefer:

```csharp
int mid = left + (right - left) / 2;
```

It avoids integer overflow in languages where `left + right` could exceed the maximum integer value. While it doesn't matter for this problem's constraints, it's considered a good habit in interviews.

---

# Complexity

Every number becomes exactly one tree node.

Time:

```text
O(n)
```

Each recursive call creates one node.

---

Space:

The recursion depth equals the tree height.

Since the tree is balanced:

```text
O(log n)
```

---

# Pattern Recognition

When you see:

* **Sorted array**
* **Balanced BST**

Think immediately:

```text
Choose the middle element as the root.
```

Then recursively build the left and right subtrees.

This belongs to the **Divide & Conquer** family of problems, where you:

1. Divide the input into smaller independent parts.
2. Solve each part recursively.
3. Combine the results.
