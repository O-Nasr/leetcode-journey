# 48. Rotate Image

# Step 1: Understand What Rotation Does

Take a simple matrix:

```text
1 2 3
4 5 6
7 8 9
```

After a **90° clockwise** rotation:

```text
7 4 1
8 5 2
9 6 3
```

Instead of thinking "rotate", ask:

> **Where does each element move?**

For example:

```text
1 → top-right
2 → middle-right
3 → bottom-right

4 → top-middle

7 → top-left
```

The index transformation is:

```text
(r, c) → (c, n - 1 - r)
```

While this formula is useful, implementing it **in-place** directly is complicated because you'll overwrite values.

---

# Step 2: Look for Simpler Transformations

The interview trick is:

Instead of one difficult transformation, perform **two easy transformations**.

For clockwise rotation:

```text
Rotate 90°
=
Transpose
+
Reverse each row
```

---

# Step 3: Transpose

Transpose means:

```text
matrix[i][j]
⇄
matrix[j][i]
```

You're reflecting across the main diagonal.

Example:

Before:

```text
1 2 3
4 5 6
7 8 9
```

After transpose:

```text
1 4 7
2 5 8
3 6 9
```

Notice:

Rows became columns.

---

## How to transpose efficiently

Only swap the **upper triangle**.

Don't swap twice.

```csharp
for (int i = 0; i < n; i++)
{
    for (int j = i + 1; j < n; j++)
    {
        Swap(matrix[i][j], matrix[j][i]);
    }
}
```

Notice:

```text
j starts from i+1
```

Otherwise you'd undo every swap.

---

# Step 4: Reverse Every Row

Current matrix:

```text
1 4 7
2 5 8
3 6 9
```

Reverse each row:

```text
7 4 1
8 5 2
9 6 3
```

Exactly what we wanted.

---

# Complete Algorithm

```text
Transpose

↓

Reverse every row
```

---

# C# Solution

```csharp
public void Rotate(int[][] matrix)
{
    int n = matrix.Length;

    // Transpose
    for (int i = 0; i < n; i++)
    {
        for (int j = i + 1; j < n; j++)
        {
            (matrix[i][j], matrix[j][i]) =
                (matrix[j][i], matrix[i][j]);
        }
    }

    // Reverse each row
    for (int i = 0; i < n; i++)
    {
        int left = 0;
        int right = n - 1;

        while (left < right)
        {
            (matrix[i][left], matrix[i][right]) =
                (matrix[i][right], matrix[i][left]);

            left++;
            right--;
        }
    }
}
```

---

# Why Does This Work?

Think geometrically.

Original:

```text
1 2 3
4 5 6
7 8 9
```

Transpose:

```text
1 4 7
2 5 8
3 6 9
```

This is a reflection across the main diagonal.

Now reverse rows:

```text
7 4 1
8 5 2
9 6 3
```

You've effectively turned the reflection into a rotation.

---

# Complexity

Every element participates in:

* one transpose swap
* one row reversal swap

Time:

```text
O(n²)
```

Space:

```text
O(1)
```

which satisfies the "in-place" requirement.

# Interview Pattern to Remember

This problem belongs to a family of **matrix transformation** problems. A useful mental map is:

| Transformation           | Steps                                                                                                                         |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| **90° clockwise**        | Transpose → Reverse each row                                                                                                  |
| **90° counterclockwise** | Transpose → Reverse each column                                                                                               |
| **180°**                 | Reverse each row → Reverse the order of the rows (or equivalently, reverse each column then reverse the order of the columns) |

The key interview skill isn't memorizing these transformations—it's recognizing that a complex matrix operation can often be decomposed into a sequence of simple, in-place operations. That's exactly what makes this solution elegant and interview-friendly.
