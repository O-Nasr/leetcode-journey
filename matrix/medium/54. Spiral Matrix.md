# 54. Spiral Matrix
**Difficulty**: medium

**LeetCode Link**:[54. Spiral Matrix](https://leetcode.com/problems/spiral-matrix/description/?envType=study-plan-v2&envId=top-interview-150) (Medium)
---

This problem is less about a special algorithm and more about **carefully managing boundaries**.

---

# Key Observation

A spiral traversal always follows this pattern:

```text
→ right
↓ down
← left
↑ up
```

Then repeat on the **inner rectangle**.

For:

```text
1 2 3
4 5 6
7 8 9
```

we traverse:

```text
1 2 3
    ↓
    6
    ↓
    9

← 8 7

↑ 4

then the remaining center:
5
```

---

# Think in Terms of 4 Boundaries

Maintain:

```csharp
top = 0;
bottom = rows - 1;

left = 0;
right = cols - 1;
```

Initially:

```text
top
 ↓
1 2 3
4 5 6
7 8 9
      ↑
    right

left = 0
bottom = 2
```

---

# After Traversing Top Row

Traverse:

```text
1 2 3
```

Then:

```csharp
top++;
```

because that row is finished.

---

# After Traversing Right Column

Traverse:

```text
6
9
```

Then:

```csharp
right--;
```

---

# After Traversing Bottom Row

Traverse:

```text
8 7
```

Then:

```csharp
bottom--;
```

---

# After Traversing Left Column

Traverse:

```text
4
```

Then:

```csharp
left++;
```

Now we're left with:

```text
5
```

Repeat until boundaries cross.

---

# Important Edge Case

Suppose:

```text
1 2 3
4 5 6
```

After moving boundaries, you may end up with:

```text
top > bottom
```

or

```text
left > right
```

If you don't check this, you'll visit elements twice.

Therefore before traversing the bottom row and left column:

```csharp
if (top <= bottom)
```

and

```csharp
if (left <= right)
```

are required.

---

# C# Solution

```csharp
public IList<int> SpiralOrder(int[][] matrix)
{
    List<int> result = new List<int>();

    int top = 0;
    int bottom = matrix.Length - 1;

    int left = 0;
    int right = matrix[0].Length - 1;

    while (top <= bottom && left <= right)
    {
        // Left -> Right
        for (int col = left; col <= right; col++)
        {
            result.Add(matrix[top][col]);
        }
        top++;

        // Top -> Bottom
        for (int row = top; row <= bottom; row++)
        {
            result.Add(matrix[row][right]);
        }
        right--;

        // Right -> Left
        if (top <= bottom)
        {
            for (int col = right; col >= left; col--)
            {
                result.Add(matrix[bottom][col]);
            }
            bottom--;
        }

        // Bottom -> Top
        if (left <= right)
        {
            for (int row = bottom; row >= top; row--)
            {
                result.Add(matrix[row][left]);
            }
            left++;
        }
    }

    return result;
}
```

# Complexity

Let:

```text
m = rows
n = cols
```

Every element is visited exactly once.

### Time

```text
O(m × n)
```

### Space

Ignoring output:

```text
O(1)
```

Including output:

```text
O(m × n)
```

# Interview Recognition Pattern

When you see:

* Matrix traversal
* Spiral / layers / rings
* Peel outer layer then move inward

Think:

```text
top
bottom
left
right
```

This "4 boundaries" technique is the standard solution and is what interviewers expect for Spiral Matrix.
